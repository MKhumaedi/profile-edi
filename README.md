## Overview

This portfolio presents my work as a Full Stack Developer with a focus on clean architecture, type-safe code, and polished user interfaces. It features an interactive 3D hero section, mouse-driven parallax effects, and a responsive layout optimized for all screen sizes.

## Features

- **Interactive Hero Section**: 3D scene, parallax motion, and a dynamic cursor-following light effect
- **Project Showcase**: curated real-world projects with screenshots and descriptions
- **Responsive Design**: mobile-first layout that adapts from phones to large desktops
- **Downloadable Resume**: one-click CV download
- **SEO Ready**: Open Graph and Twitter Card metadata for rich link previews
- **Fast Deployments**: hosted on Vercel with automatic builds from Git

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/MKhumaedi/profile-edi.git

# Move into the project directory
cd profile-edi

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build

```bash
npm run build
```

## Deployment

The site is deployed on [Vercel](https://vercel.com). Every push to the `master` branch triggers an automatic build and deployment.
